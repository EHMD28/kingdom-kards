# Kingdom Kards

> [!IMPORTANT]
> This project is still a work-in-progress. All of the features seen in this readme are not fully
> supported yet.

This project is a game server for my playing card game, Kingdom Kards. The server is hosted on the 
computer's Local Area Network (LAN), so anyone on the same network can join. For the complete rules 
of Kingdom Kards, see [Rules.md](Rules.md) 

# Server

To start the server, run
```
cargo r -- server
```

# Client

To start the client, run 
```
cargo r -- client
```
